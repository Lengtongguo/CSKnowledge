# CSKnowledge

一个面向计算机求职面试的知识库，记录和整理常见的计算机基础知识、原理分析与面试题思路。

## 项目简介

本项目希望把零散的“八股”整理成一套便于复习、理解和持续补充的知识体系。内容以问题为入口，尽量说明结论背后的原理、适用场景和常见追问，帮助建立可迁移的知识框架，而不只是记忆标准答案。

## 主要方向

后续内容计划围绕以下主题逐步完善：

- 数据结构与算法
- 操作系统
- 计算机网络
- 数据库
- Java / JVM 与常用开发基础
- Redis、消息队列等常见中间件
- 分布式系统与系统设计
- 项目经历与面试表达

## 使用方式

建议按照“先理解原理，再结合场景，最后进行口头复述”的方式复习：

1. 先通读对应主题，建立整体知识框架。
2. 对不熟悉的概念补充源码、实验或官方文档阅读。
3. 尝试在限定时间内独立回答问题，并记录遗漏点。
4. 根据面试反馈持续修订内容，补充常见追问和实际案例。

## 内容规范

- 优先记录可解释、可验证的结论，避免只保留一句话答案。
- 对容易混淆的概念进行对比，明确边界和使用条件。
- 涉及版本、实现细节或性能数据时，注明适用范围和参考来源。
- 发现错误或过时内容时及时修正，保持知识库可维护。
